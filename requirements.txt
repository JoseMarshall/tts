# --- Model backends (install only what you use) ---
# The default "mock" backend needs none of these, so the server runs anywhere
# for testing. Install the deps for whichever real backend you select.
#
# Qwen3-TTS  (TTS_BACKEND=qwen)  -- needs a CUDA GPU:
#   pip install -U torch qwen-tts soundfile
#   # torch build must match your CUDA (e.g. --index-url .../whl/cu128)
#
# Kokoro-82M (TTS_BACKEND=kokoro) -- runs on CPU or GPU, ~350 MB:
#   pip install -U kokoro soundfile
#   # also install the espeak-ng system package for full G2P / non-English:
#   #   Windows: winget install eSpeak-NG.eSpeak-NG   (or the MSI release)
#   #   Debian/Ubuntu: sudo apt-get install espeak-ng
#   #   macOS: brew install espeak-ng
#
# Dia-1.6B  (TTS_BACKEND=dia)  -- needs a CUDA GPU:
#   pip install -U git+https://github.com/nari-labs/dia.git soundfile
#
# Multiple backends can be installed together and selected per request; see
# TTS_BACKENDS in .env.example.
#
# --- Voice activity detection (/v1/stt_ws turn endpointing, optional) ---
# Only needed if a client enables VAD; nothing is imported until then.
#   STT_VAD=silero (default, accurate, runs on CPU):
#     pip install silero-vad torch
#   STT_VAD=webrtc:
#     pip install webrtcvad
#   STT_VAD=energy needs nothing — it is the zero-dependency fallback.
